# IIIF Annotator 使い方ガイド

## 概要

IIIF Annotatorは、IIIF（International Image Interoperability Framework）準拠のマニフェストファイルに対してアノテーション（注釈）を追加・編集できるWebアプリケーションです。

## ログインについて

本アプリケーションはFirebaseを使用してアノテーションを保存します。機能を利用するには、まずログインが必要です。

### ログイン方法
1. 画面右上の「ログイン」ボタンをクリック
2. 以下のいずれかの方法でログイン：
   - **Googleアカウント**: 「Googleでログイン」ボタンをクリック（推奨）
   - **メールアドレス**: メールアドレスとパスワードを入力
   - **新規登録**: 「新規アカウント作成」から登録

### ログイン後の機能
- アノテーションがFirebaseクラウドに自動保存
- 複数デバイスからアクセス可能
- 他のユーザーと共同作業が可能

### ログアウト
- 画面右上のユーザーアイコンから「ログアウト」を選択

## 主な機能

### 1. IIIFコレクションの閲覧
- IIIFコレクションURLを入力して、コレクション内のマニフェスト一覧を表示
- 階層的なコレクション構造をナビゲート可能
- サムネイル画像付きでマニフェストを視覚的に確認

### 2. マニフェストの編集
- IIIFマニフェストURLを直接指定して編集画面へ移動
- OpenSeadragonを使用した高性能な画像ビューア
- ズーム、パン、回転などの画像操作

### 3. アノテーション機能
- 画像上に矩形選択でアノテーション領域を作成
- リッチテキストエディタでアノテーション内容を編集
- アノテーションの一覧表示と管理

### 4. エクスポート機能
- アノテーションをW3C Web Annotation形式でエクスポート
- TEI（Text Encoding Initiative）形式でのエクスポート

## 使い方

### ホーム画面

ホーム画面では2つの入力フォームが表示されます：

#### マニフェストを編集
1. 「Manifest URL」フィールドにIIIFマニフェストのURLを入力
2. オプションで「ページ番号」を指定（複数ページのマニフェストの場合）
3. 「編集画面へ」ボタンをクリック

#### コレクションを表示
1. 「Collection URL」フィールドにIIIFコレクションのURLを入力
2. 「コレクション表示」ボタンをクリック

### コレクション画面

コレクション画面では以下の操作が可能です：

- **マニフェストの選択**: カードをクリックして編集画面へ移動
- **サブコレクション**: フォルダーアイコンのカードをクリックして階層を深く探索
- **戻るボタン**: 親コレクションまたはホーム画面へ戻る
- **表示切り替え**: グリッド表示とリスト表示の切り替え（実装予定）

### 編集画面

編集画面の主な機能：

#### 画像操作
- **ズーム**: マウスホイールまたは +/- ボタン
- **パン**: マウスドラッグで画像を移動
- **全画面表示**: フルスクリーンボタンで最大化
- **ホーム**: 画像を初期表示に戻す

#### アノテーション作成
1. ツールバーのポリゴン（多角形）選択ツールをクリック
2. 画像上でクリックして頂点を追加していく
3. 領域を囲むように複数の点をクリックして多角形を作成
4. **終了方法**：
   - ダブルクリックで現在の位置で終了
   - または開始点（最初の点）に戻ってクリックで閉じる
5. ポップアップエディタでテキストを入力
6. 保存ボタンでアノテーションを確定

**ヒント**: 矩形ツールも利用可能ですが、より柔軟な選択にはポリゴンツールをお勧めします。

#### アノテーション管理
- **一覧表示**: サイドパネルでアノテーション一覧を確認
- **並び替え**: ドロップダウンメニューから作成日順・名前順で並び替え
- **編集**: アノテーションをクリックして内容を編集
- **削除**: アノテーションを選択して削除
- **複数選択**: 選択モードボタンをクリックして複数のアノテーションを選択し、一括削除が可能
- **フォーカス**: 標的アイコンをクリックしてビューア上でアノテーションにフォーカス
- **エクスポート**: 作成したアノテーションをダウンロード

#### ショートカットキー
効率的にアノテーションを作成・編集するために、以下のショートカットキーが利用できます：

**ツール切り替え:**
- **M**: 選択モード（Move）- アノテーションの選択と移動
- **B**: 矩形モード（Box）- 矩形領域でアノテーションを作成
- **P**: ポリゴンモード（Polygon）- 多角形領域でアノテーションを作成

**編集操作:**
- **T**: テキストエディタにフォーカス（ツール選択中またはアノテーション選択中）
- **Ctrl+S / Cmd+S**: アノテーションを保存（アノテーション選択中）

※ショートカットキーは、入力フィールドやテキストエリアにフォーカスがない場合のみ動作します。

### その他の機能

#### Miradorで開く
編集画面で「Miradorで開く」ボタンをクリックすると、現在のマニフェストをMirador（IIIFビューア）で表示できます。Miradorでは複数の画像を並べて比較したり、詳細な画像解析が可能です。

#### 言語切り替え
画面右上の言語選択メニュー（JP/EN）から日本語と英語を切り替えられます。設定は自動的に保存されます。

#### テーマ切り替え
画面右上の太陽/月アイコンをクリックして、ライトモードとダークモードを切り替えられます。目の疲れを軽減したい場合はダークモードをお勧めします。

## 対応フォーマット

### 入力
- IIIF Presentation API v2.x
- IIIF Presentation API v3.0
- 自動的にv2をv3に変換して処理

### 出力
- W3C Web Annotation
- TEI (Text Encoding Initiative)

## システム要件

- モダンブラウザ（Chrome, Firefox, Safari, Edge）
- JavaScript有効
- インターネット接続（IIIFリソースへのアクセス用）

## トラブルシューティング

### コレクションが表示されない
- URLが正しいか確認してください
- CORSポリシーにより一部のサーバーからは取得できない場合があります
- ブラウザのコンソールでエラーを確認してください

### 画像が表示されない
- IIIFマニフェストのURLが正しいか確認
- 画像サーバーがアクセス可能か確認
- ネットワーク接続を確認

### アノテーションが保存されない
- ログインしているか確認
- インターネット接続を確認
- Firebaseへのアクセスがブロックされていないか確認
